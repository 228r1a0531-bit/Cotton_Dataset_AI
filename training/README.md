# Training

Install `requirements-ml.txt` and use **Dataset & Training** in the Streamlit
dashboard to fit the baseline CNN. Fast Demo runs a small configurable number of
epochs. Full training uses 50 epochs. Validation and test data are resized and
rescaled deterministically. The test split is evaluated after training.

See the repository README for dataset setup and `results/README.md` for the run
artifacts and checkpoint configuration.
